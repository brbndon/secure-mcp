# Attribution

Patterns in secure-mcp knowledge packs are **inspired by** themes commonly found in public agent-skill and secure-code-review ecosystems, then rewritten into this project’s defensive checklist schema (evidence → classify → remediate).

Themes referenced at a high level (not vendored as source files):

- General secure code review and secrets hygiene (e.g. Sentry / OpenAI-style security review skill themes)
- Threat-modeling / STRIDE-oriented control planning themes
- Next.js and web API hardening themes (middleware depth, public env, Server Actions, CSRF/cookies)
- Apple / Swift storage and privacy themes (Keychain, ATS, WebView, entitlements)
- Mobile / Expo secure-storage and config-secret themes

The knowledge packs do **not** vendor third-party `SKILL.md` content. Pack items are original structured checklists maintained by secure-mcp. Do not paste attribution essays into tool responses.
