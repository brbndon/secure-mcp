# Support

Use [GitHub Issues](https://github.com/brbndon/secure-mcp/issues) for reproducible bugs, setup questions, and feature requests. Search existing issues before opening a new one, and include the secure-mcp version, client, operating system, relevant configuration with secrets removed, and the smallest safe reproduction.

Do not post credentials, private source code, or sensitive audit output in a public issue.

## Security vulnerabilities

Report product vulnerabilities privately via
[GitHub Security Advisories](https://github.com/brbndon/secure-mcp/security/advisories/new).
See [SECURITY.md](SECURITY.md). Do not file them as public issues.
